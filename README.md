# Apple TV Style Android TV Launcher

Apple TV-inspired starter launcher for Android TV, intended for testing on H96 Max RK3318 / Android 9.

## Build APK
1. Upload the contents of this project to the root of a GitHub repository.
2. Open **Actions** and allow workflows if GitHub asks.
3. Select **Build Android APK** and click **Run workflow**, or push a commit.
4. Open the completed run and download the `AppleTVLauncher-debug-apk` artifact.
5. Extract the ZIP to get `app-debug.apk`.

App shortcuts are for YouTube, Fastway Live TV, NetMirror, and Hotstar. These apps must already be installed on the TV.

Keep the stock launcher installed until testing is complete. This is not an official Apple product and it does not automatically become the default HOME launcher.
